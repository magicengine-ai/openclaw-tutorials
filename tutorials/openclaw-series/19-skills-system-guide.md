## 3. 安装 Skills

### 3.1 从 SkillHub 安装

**SkillHub 是 OpenClaw 的官方技能市场。**

```bash
# 查看可用 Skills
openclaw skills list

# 搜索 Skills
openclaw skills search 股票

# 安装 Skill
openclaw skills install stock-analysis

# 查看已安装的 Skills
openclaw skills installed
```

### 3.2 手动安装

```bash
# 从 GitHub 克隆
cd ~/.openclaw/skills
git clone https://github.com/xxx/skill-name.git

# 安装依赖
cd skill-name
npm install

# 启用 Skill
openclaw skills enable skill-name
```

### 3.3 配置文件

```json
// ~/.openclaw/config.json
{
  "skills": {
    "enabled": [
      "stock-analysis",
      "xiaohongshu-ops",
      "pdf-generator"
    ],
    "disabled": [],
    "config": {
      "stock-analysis": {
        "apiKey": "your-api-key",
        "defaultMarket": "US"
      }
    }
  }
}
```

## 5. 管理 Skills

### 5.1 启用/禁用 Skill

```bash
# 启用 Skill
openclaw skills enable skill-name

# 禁用 Skill
openclaw skills disable skill-name

# 查看 Skill 状态
openclaw skills status
```

### 5.2 更新 Skills

```bash
# 更新单个 Skill
openclaw skills update stock-analysis

# 更新所有 Skills
openclaw skills update --all

# 查看可更新的 Skills
openclaw skills outdated
```

### 5.3 卸载 Skills

```bash
# 卸载 Skill
openclaw skills uninstall skill-name

# 清理缓存
openclaw skills clean
```

### 5.4 Skill 配置

```json
// 配置 Skill 参数
{
  "skills": {
    "config": {
      "stock-analysis": {
        "apiKey": "your-api-key",
        "defaultMarket": "US",
        "refreshInterval": 300
      },
      "xiaohongshu-ops": {
        "account": "your-account",
        "autoPublish": false
      }
    }
  }
}
```

## 8. Skills 最佳实践

### 8.1 选择 Skills

```
✅ 推荐做法：

1. 优先选择官方 Skills
   - 质量保证
   - 定期更新
   - 文档完善

2. 查看评分和评论
   - 用户反馈
   - 使用体验
   - 问题报告

3. 检查更新频率
   - 最近更新时间
   - 维护状态
   - 开发者活跃度

4. 阅读文档
   - 功能说明
   - 配置要求
   - 使用示例
```

### 8.2 配置 Skills

```
✅ 推荐做法：

1. 安全存储凭证
   - 使用环境变量
   - 不要硬编码在配置文件
   - 定期更新密钥

2. 最小权限原则
   - 只授予必要权限
   - 定期审查权限
   - 禁用不用的 Skills

3. 备份配置
   - 定期备份 Skill 配置
   - 版本控制配置文件
   - 记录配置变更
```

### 8.3 维护 Skills

```
✅ 推荐做法：

1. 定期更新
   - 每月检查更新
   - 及时安装安全补丁
   - 关注更新日志

2. 监控性能
   - 注意资源占用
   - 检查错误日志
   - 优化配置

3. 清理不用的 Skills
   - 禁用长期不用的
   - 卸载不需要的
   - 保持系统简洁
```

## 9. 常见问题

### 9.1 安装问题

```
问题 1：Skill 安装失败

可能原因：
1. 网络问题
2. 依赖冲突
3. 版本不兼容

解决方案：
- 检查网络连接
- 查看错误日志
- 尝试手动安装
- 联系开发者
```

### 9.2 配置问题

```
问题 2：Skill 无法使用

可能原因：
1. 未启用
2. 配置错误
3. 缺少凭证

解决方案：
- 检查启用状态：openclaw skills status
- 检查配置文件
- 补充必要凭证
- 重启 Gateway
```

### 9.3 性能问题

```
问题 3：Skill 运行慢

可能原因：
1. 资源不足
2. API 限流
3. 网络延迟

解决方案：
- 检查系统资源
- 调整请求频率
- 使用缓存
- 升级配置
```
