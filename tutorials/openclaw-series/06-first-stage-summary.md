## 📚 第一阶段知识回顾

恭喜你完成了第一阶段的学习！让我们回顾一下这 5 篇的核心内容：

### 第 01 篇：OpenClaw 是什么？

**核心要点：**
- OpenClaw = AI 大脑 + 执行能力
- 开源、自托管、免费使用
- 可以真正执行任务（不只是聊天）

**关键区别：**
```
传统 AI：我只能告诉你怎么做
OpenClaw：我可以帮你做
```

---

### 第 02 篇：OpenClaw 能做什么？

**核心能力：**
| 能力 | 示例 |
|------|------|
| 文件操作 | 读取、写入、整理文件 |
| 网络搜索 | 实时查新闻、查资料 |
| 浏览器控制 | 自动填表、点击、截图 |
| 消息发送 | 飞书/微信/Telegram 发消息 |
| 日程管理 | 创建会议、设置提醒 |
| 任务管理 | 创建待办、跟踪进度 |

---

### 第 03 篇：OpenClaw 的工作原理

**Agent 思考流程：**
```
1. 接收任务 → 2. 理解意图 → 3. 选择工具 → 4. 执行操作 → 5. 返回结果
```

**记忆系统：**
- 短期记忆：当前会话上下文
- 长期记忆：MEMORY.md 文件
- 工具记忆：TOOLS.md 配置文件

---

### 第 04 篇：OpenClaw 的架构组成

**三大核心组件：**

| 组件 | 作用 | 比喻 |
|------|------|------|
| **Gateway** | 消息路由、会话管理 | 前台接待 |
| **Node** | 执行具体任务 | 工作人员 |
| **Channel** | 连接外部平台 | 通信渠道 |

**架构简图：**
```
你 → Channel → Gateway → Node → 工具 → 结果
```

---

### 第 05 篇：OpenClaw 与其他 AI 工具的区别

**对比总结：**

| 特性 | ChatGPT | OpenClaw |
|------|---------|----------|
| 执行能力 | ❌ | ✅ |
| 数据隐私 | ⚠️ 云端 | ✅ 本地 |
| 费用 | $20/月 | 🆓 免费 |
| 自动化 | ❌ | ✅ 24/7 |

**最佳方案：组合使用**
- ChatGPT：高质量对话、创意写作
- OpenClaw：自动化任务、本地操作
