## 2. 基础操作

### 2.1 打开网页

**对话示例：**

```
你：帮我打开 GitHub 首页

OpenClaw: 好的，正在打开网页...

🌐 已打开：https://github.com

页面标题：GitHub: Let's build from here

需要我做什么操作吗？
```

**对应的工具调用：**

```json
{
  "name": "browser",
  "action": "open",
  "request": {
    "url": "https://github.com"
  }
}
```

### 2.2 导航到指定页面


## 4. 截图功能

### 4.1 页面截图

```
你：帮我截个图

OpenClaw: 好的，正在截图...

📸 截图完成

[图片已保存]
保存路径：~/openclaw/screenshots/github-2026-03-26-110000.png

需要我发送给你吗？
```

**对应的工具调用：**

```json
{
  "name": "browser",
  "action": "screenshot",
  "request": {
    "type": "png",
    "fullPage": true
  }
}
```

### 4.2 截图参数

| 参数 | 说明 | 可选值 | 默认值 |
|------|------|--------|--------|
| `type` | 图片格式 | png/jpeg | png |
| `fullPage` | 是否整页截图 | true/false | false |
| `width` | 截图宽度 | 像素值 | 自动 |
| `height` | 截图高度 | 像素值 | 自动 |

### 4.3 截图应用场景

```
✅ 适合截图的场景：

1. 网页视觉验证
   "截图看看页面是否正常显示"

2. 错误记录
   "截图保存这个错误页面"

3. 内容存档
   "截图保存这个限时内容"

4. 操作确认
   "截图确认提交成功"
```

## 8. 浏览器配置

### 8.1 浏览器选择

```json
// config.json 中的浏览器配置
"browser": {
  "profile": "user",        // 使用用户浏览器
  "timeout": 30000,         // 超时时间（毫秒）
  "headless": false         // 是否无头模式
}
```

| profile | 说明 | 适用场景 |
|---------|------|----------|
| `user` | 使用用户浏览器 | 需要登录状态 |
| `openclaw` | 独立浏览器 | 隔离环境 |
| `chrome-relay` | Chrome 扩展 | 扩展集成 |

### 8.2 超时配置

```
timeout 设置：
- 短操作（点击/输入）：5000ms
- 页面加载：30000ms
- 复杂操作：60000ms

超时处理：
- 自动重试 1 次
- 失败后返回错误信息
- 建议检查网络连接
```

## 9. 常见问题排查

### 9.1 元素找不到

```
❌ 问题：点击失败，元素不存在

可能原因：
1. 页面未完全加载
2. 元素 ID/选择器变化
3. 在 iframe 内

✅ 解决方案：
- 等待页面加载完成
- 使用快照查看可用元素
- 切换到正确的 frame

示例：
你：点击登录按钮
OpenClaw: 抱歉，没有找到这个元素。
        让我先获取页面快照...
        找到了，应该是这个元素 [e3]
        正在点击...
```

### 9.2 操作超时

```
❌ 问题：操作超时

可能原因：
1. 网络慢
2. 页面复杂
3. 目标网站限制

✅ 解决方案：
- 增加超时时间
- 检查网络连接
- 尝试其他方式

示例：
OpenClaw: 操作超时（30 秒）
        可能是网络问题或网站限制。
        要再试一次吗？
```

### 9.3 登录状态丢失

```
❌ 问题：每次都要重新登录

可能原因：
1. 使用独立浏览器
2. Cookie 未保存
3. 会话过期

✅ 解决方案：
- 使用 user profile
- 保存登录状态
- 定期刷新会话

示例：
你：总是需要重新登录
OpenClaw: 建议配置使用用户浏览器。
        这样可以保持登录状态。
        修改配置：browser.profile = "user"
```
