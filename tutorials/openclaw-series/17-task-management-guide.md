### 1.3 任务 vs 日程

| 特性 | 任务 (Task) | 日程 (Calendar) |
|------|-------------|-----------------|
| 用途 | 待办事项 | 会议/约会 |
| 时间 | 截止时间 | 具体时间段 |
| 参与人 | 可选 | 通常需要 |
| 提醒 | 截止前提醒 | 开始前提醒 |
| 状态 | 未完成/已完成 | 已接受/已拒绝 |

## 2. 创建任务

### 2.1 基本任务创建

**对话示例：**

```
你：帮我创建一个任务，完成项目报告，下周五截止

OpenClaw: 好的，正在创建任务...

✅ 任务已创建

📋 任务详情：
- 标题：完成项目报告
- 截止时间：2026-04-05（下周五）
- 优先级：中
- 状态：未完成
- 创建时间：2026-03-26

需要我设置提醒吗？
```

**对应的工具调用：**

```json
{
  "name": "task",
  "action": "create",
  "summary": "完成项目报告",
  "due": {
    "timestamp": "2026-04-05T18:00:00+08:00"
  }
}
```

### 2.2 任务参数详解

```json
{
  "summary": "任务标题",           // 必填
  "description": "任务描述",       // 可选
  "due": {                         // 截止时间
    "timestamp": "2026-04-05T18:00:00+08:00",
    "is_all_day": false
  },
  "members": [                     // 任务成员
    {
      "id": "ou_xxxxx",
      "role": "assignee"           // assignee=负责人，follower=关注人
    }
  ],
  "priority": "medium"             // 优先级
}
```

## 8. 任务管理技巧

### 8.1 任务分解

```
❌ 不好的任务：
"完成项目"（太大、太模糊）

✅ 好的任务分解：
"完成项目" → 分解为：
- [ ] 需求分析
- [ ] 设计方案
- [ ] 编码实现
- [ ] 测试验证
- [ ] 部署上线

💡 原则：每个任务应该是可执行、可衡量的
```

### 8.2 优先级管理

```
📊 优先级矩阵：

        紧急
         ↑
    重要 │  既重要又紧急   │  重要不紧急
         │  (立即做)      │  (计划做)
    -----│----------------│----------
         │  紧急不重要    │  不紧急不重要
         │  (授权做)      │  (少做)
         └──────────────────────────→
```

### 8.3 时间估算

```
任务时间估算技巧：

1. 参考类似任务的历史时间
2. 增加 20% 缓冲时间
3. 考虑依赖和等待时间
4. 避免过度乐观

示例：
"写报告" → 实际可能需要 4 小时
不要只估算 2 小时
```

## 10. 常见问题

### 10.1 任务太多怎么办？

```
问题：任务列表太长，看不过来

解决方案：
1. 按优先级筛选
2. 按时间筛选（今天/本周）
3. 批量处理相似任务
4. 委托或推迟不重要的

示例：
你：只显示今天的高优先级任务
OpenClaw: 好的，筛选中...
        今天有 3 个高优先级任务。
```

### 10.2 忘记任务怎么办？

```
问题：总是忘记任务

解决方案：
1. 设置多个提醒时间点
2. 使用多渠道提醒
3. 每天早晚查看任务列表
4. 让 OpenClaw 主动推送

示例：
你：重要任务多提醒几次
OpenClaw: 好的，已设置：
        - 截止前 1 天
        - 截止前 3 小时
        - 截止前 30 分钟
```

```
问题：会议时间冲突

1. 创建会议前查询忙闲
```

## 13. 本篇总结

### 📌 核心要点

1. **任务管理**：create（创建）、list（查看）、update（更新）、get（详情）
2. **日程管理**：创建会议、查询忙闲、重复日程
3. **提醒设置**：一次性提醒、重复提醒、截止前提醒
4. **任务分解**：大任务拆分为小任务，便于执行
5. **优先级管理**：使用优先级矩阵，先做重要且紧急的
6. **最佳实践**：每日规划、合理截止、定期回顾、及时更新
