## 2. 第一次对话

### 2.1 通过消息渠道

**步骤 1：打开消息应用**

```
飞书用户：
1. 打开飞书
2. 搜索你的机器人名称
3. 点击进入聊天

Telegram 用户：
1. 打开 Telegram
2. 搜索你的机器人
3. 点击进入聊天

Discord 用户：
1. 打开 Discord
2. 进入有机器人的频道
3. 准备发送消息
```

**步骤 2：发送第一条消息**

```
推荐的第一条消息：

"你好"
"Hello"
"在吗？"

这些都是很好的开始！
```

**步骤 3：期待回复**

```
期望的回复（1-3 秒内）：

🦞 OpenClaw:
你好！我是你的 AI 助手 OpenClaw。
我已经准备好帮你了，有什么可以做的吗？

我可以帮你：
• 查找信息
• 管理文件
• 发送消息
• 创建待办
• 等等...
```

## 3. 有效沟通的基本原则

### 3.1 清晰具体

```
❌ 模糊的请求：
"帮我弄一下那个文件"

✅ 清晰的请求：
"帮我读取 ~/workspace/meetings/2026-03-26.md 文件"

💡 原则：明确说明要做什么、操作什么对象
```

### 3.2 完整上下文

```
❌ 缺少上下文：
"总结一下"

✅ 提供上下文：
"总结一下刚才我让你读取的那个会议记录"

💡 原则：如果涉及之前的内容，提供足够上下文
```

### 3.3 分步复杂任务

```
❌ 一次性太复杂：
"帮我把所有文件整理好，然后发邮件给大家，再创建会议"

✅ 分步进行：
1. "帮我列出 workspace 里的所有文件"
2. "把这些文件按日期分类"
3. "给团队发个消息，说文件已整理好"
4. "创建一个会议，讨论这些文件"

💡 原则：复杂任务分解成多个简单步骤
```

### 3.4 指定输出格式

```
❌ 不指定格式：
"帮我整理这些数据"

✅ 指定格式：
"帮我整理这些数据，用表格形式展示"
"帮我整理这些数据，输出为 Markdown 列表"

💡 原则：告诉 Agent 你想要的输出格式
```

## 4. 提示词（Prompt）技巧

### 4.1 角色设定

```
技巧：给 Agent 设定一个角色，让它更好地理解任务

示例：
"你是一个专业的文件管理员，帮我整理这些文件..."
"你是一个研究助手，帮我搜索以下主题的资料..."
"你是一个日程助理，帮我安排下周的会议..."

效果：Agent 会按照角色定位来组织回复
```

### 4.2 任务分解

```
技巧：复杂任务分解为清晰步骤

示例：
"请按照以下步骤操作：
1. 首先，读取 ~/workspace/todo.md 文件
2. 然后，找出所有未完成的任务
3. 最后，创建一个汇总表"

效果：Agent 会按步骤执行，更可靠
```

### 4.3 示例引导

```
技巧：提供示例，让 Agent 理解你的期望

示例：
"帮我格式化这些日期，像这样：
输入：2026-03-26
输出：2026 年 3 月 26 日

现在请格式化：2026-01-15, 2026-06-30"

效果：Agent 会模仿示例的格式
```

### 4.4 约束条件

```
技巧：明确说明限制和要求

示例：
"帮我搜索 AI 新闻，只要最近 3 天的，最多 5 条"
"帮我写一封邮件，不超过 200 字，语气正式"
"帮我整理文件，不要修改原文件，创建新文件"

效果：Agent 会在约束范围内工作
```

### 4.5 确认机制

```
技巧：重要操作前要求确认

示例：
"帮我删除这些文件，删除前请先列出来让我确认"
"帮我发送这个消息，发送前请给我看一下草稿"

效果：避免误操作，增加安全性
```

## 5. 常见对话场景

### 5.1 信息查询

```
场景：想了解某个主题的信息

❌ 不够好：
"查一下 AI"

✅ 更好：
"帮我搜索一下最近一周关于人工智能的最新进展，
只要中文新闻，5 条以内"

✅ 还可以追问：
"第三条新闻详细说一下"
"把这些新闻保存到文件里"
```

### 5.2 文件操作

```
场景：需要处理文件

❌ 不够好：
"帮我处理文件"

✅ 更好：
"帮我读取 ~/workspace/project/README.md 文件"
"帮我把这个文件里的版本号从 1.0 改成 1.1"
"帮我创建一个新文件，路径是 ~/workspace/notes.md，
内容是今天的会议记录"

✅ 还可以组合：
"先读取文件，然后修改，最后保存"
```

### 5.3 消息发送

```
场景：需要通知他人

❌ 不够好：
"发消息给张三"

✅ 更好：
"给张三发个消息，说明天下午 3 点的会议改到 4 点"
"在团队群里发个通知，说项目进度正常，预计周五完成"

✅ 还可以定制：
"消息语气要正式一点"
"加上表情符号，让消息友好一些"
```

### 5.4 日程管理

```
场景：需要安排日程

❌ 不够好：
"帮我安排会议"

✅ 更好：
"帮我创建一个会议，明天下午 2 点，主题是项目评审，
参加人有张三、李四、王五，时长 1 小时"

✅ 还可以细化：
"会议地点定在 302 会议室"
"创建飞书视频会议链接"
"会议前一天提醒我"
```

### 5.5 任务管理

```
场景：需要管理待办事项

❌ 不够好：
"帮我记一下"

✅ 更好：
"帮我创建一个任务：完成项目报告，下周五截止，
优先级高"

✅ 还可以追踪：
"查看我这周的所有任务"
"标记任务'完成报告'为已完成"
"给这个任务添加一个子任务：收集数据"
```

## 7. 避免常见错误

### 7.1 模糊不清

```
❌ 错误：
"帮我弄一下"
"那个文件"
"发个消息"

✅ 正确：
"帮我读取 ~/workspace/test.md 文件"
"发个消息给张三，说明天会议改时间"
```

### 7.2 假设太多

```
❌ 错误：
"你知道的，帮我处理一下"
（Agent 不知道你知道什么）

✅ 正确：
"帮我处理昨天我们讨论的那个项目文件，
路径是 ~/workspace/project/"
```

### 7.3 一次性太多

```
❌ 错误：
"帮我读文件、改内容、发邮件、创建会议、
设置提醒、整理笔记、搜索资料..."

✅ 正确：
分步进行，一步完成后进行下一步
```

### 7.4 不检查输出

```
❌ 错误：
（直接相信所有输出）

✅ 正确：
重要操作前要求确认：
"删除前请先列出来让我确认"
"发送前给我看一下草稿"
```

## 8. 高级对话技巧

### 8.1 上下文引用

```
技巧：引用之前的对话内容

示例：
你："帮我读取 ~/workspace/report.md"
Agent: [读取并显示内容]
你："把刚才那个文件里的第二段改一下"

💡 Agent 会理解"刚才那个文件"指的是 report.md
```

### 8.2 条件逻辑

```
技巧：使用条件语句

示例：
"如果文件存在就读取，不存在就创建"
"如果搜索结果为空，就告诉我没找到"

💡 Agent 会按条件执行不同操作
```

### 8.3 迭代优化

```
技巧：不满意就要求修改

示例：
你："帮我写一封邮件"
Agent: [生成邮件]
你："语气再正式一点，加上项目名称"
Agent: [修改后版本]
你："好了，发送吧"

💡 多轮对话优化结果
```

### 8.4 批量操作

```
技巧：一次性处理多个项目

示例：
"帮我读取 workspace 里所有的.md 文件"
"给这三个人都发个消息：张三、李四、王五"
"创建 5 个任务，分别是..."

💡 提高效率，减少重复
```
