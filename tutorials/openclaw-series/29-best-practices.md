```

   • 测试环境：test.config.json

   • 配置模板提交到版本控制
   • 敏感信息使用环境变量
   • .env 文件不提交

4. 配置备份
   • 定期备份配置
   • 异地存储备份
   • 测试恢复流程
```

```
│     • Token: 按过期时间                                 │

│  4. 使用凭证管理工具                                    │
│     • 1Password                                         │
│     • LastPass                                          │
│     • pass (Linux)                                      │
│                                                         │
│  ❌ 一定不要：                                          │
│                                                         │
│  1. 提交凭证到版本控制                                  │
│  2. 通过明文传输凭证                                    │
│  3. 在日志中记录凭证                                    │
│  4. 共享个人凭证                                        │
│                                                         │
```

### 3.2 访问控制

```json
// 推荐的访问控制配置

{
  "security": {
    "accessControl": {
      "enabled": true,
      "defaultPolicy": "deny",
      "roles": {
        "admin": {
          "permissions": ["*"]
        },
        "user": {
          "permissions": [
            "read:*",
            "write:workspace/*",
            "search:*"
          ]
        }
      }
    },
    "fileAccess": {
      "allowedPaths": ["~/openclaw/workspace"],
      "deniedPaths": ["/etc", "/root", "/home/*/.ssh"]
    },
    "toolAccess": {
      "allowedTools": ["read", "write", "search"],
      "deniedTools": ["exec"],
      "restrictedTools": {
        "exec": {
          "requireApproval": true,
          "allowlist": ["ls", "cat", "grep"]
        }
      }
    }
  }
}
```

## 7. 常见陷阱与避免

### 7.1 部署陷阱

| 陷阱 | 表现 | 后果 | 避免方法 |
|------|------|------|----------|
| **配置错误** | 系统无法启动 | 服务中断 | 配置验证、测试环境先测 |
| **凭证泄露** | 配置文件提交 | 账号被盗 | 使用环境变量、.gitignore |
| **无备份** | 配置丢失 | 恢复困难 | 定期备份、版本控制 |
| **资源不足** | 系统缓慢 | 体验差 | 监控资源、及时扩容 |

### 7.2 安全陷阱

| 陷阱 | 表现 | 后果 | 避免方法 |
|------|------|------|----------|
| **权限过大** | 所有用户 admin | 风险高 | 最小权限、角色分离 |
| **凭证硬编码** | Key 在代码中 | 泄露风险 | 环境变量、密钥管理 |
| **无审计日志** | 无法追溯 | 难以定责 | 启用审计、定期审查 |
| **不更新** | 漏洞未修复 | 安全风险 | 定期更新、关注公告 |

### 7.3 性能陷阱

| 陷阱 | 表现 | 后果 | 避免方法 |
|------|------|------|----------|
| **无缓存** | 重复调用 | 速度慢、成本高 | 启用缓存、设置 TTL |
| **并发过高** | 系统过载 | 服务不可用 | 限流、队列 |
| **内存泄漏** | 内存增长 | 系统崩溃 | 监控、定期重启 |
| **大文件处理** | 一次性加载 | 内存溢出 | 流式处理、分块 |

### 7.4 开发陷阱

| 陷阱 | 表现 | 后果 | 避免方法 |
|------|------|------|----------|
| **无错误处理** | 崩溃无提示 | 用户体验差 | 捕获异常、友好提示 |
| **无测试** | Bug 多 | 质量差 | 单元测试、集成测试 |
| **无文档** | 不会用 |  adoption 低 | 写文档、示例代码 |
| **过度设计** | 复杂难用 | 维护困难 | 简单优先、逐步迭代 |
