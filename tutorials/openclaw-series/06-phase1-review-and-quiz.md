## 2. 核心知识点梳理

### 2.1 OpenClaw 的定义

> **OpenClaw = AI 大脑 + 执行能力**

更准确地说：

> **OpenClaw 是一个开源的、可自托管的 AI Agent 运行平台**

**关键词理解：**

| 关键词 | 含义 | 为什么重要 |
|--------|------|------------|
| **开源** | 代码公开，免费使用 | 可以审计、修改、扩展 |
| **自托管** | 运行在你的设备上 | 数据隐私、完全控制 |
| **AI Agent** | 能自主完成任务 | 不只是聊天，能真正做事 |
| **平台** | 可以连接各种工具 | 无限扩展可能性 |

---

### 2.2 核心能力（6 大类）

```
┌─────────────────────────────────────────────────────────┐
│              OpenClaw 6 大类核心能力                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  📁 文件操作    读取、写入、编辑、整理文件               │
│  🔍 信息获取    网络搜索、网页抓取、信息监控             │
│  🌐 浏览器      自动化网页操作、截图、填表               │
│  💬 消息通信    飞书/微信/Telegram/Discord 发消息        │
│  📅 日程任务    日历管理、待办事项、定时提醒             │
│  🔧 系统控制    执行命令、管理进程、后台任务             │
│                                                         │

| 执行命令 | `exec` | 运行脚本、自动化 |

### 2.3 工作原理（简化版）

```
┌─────────────────────────────────────────────────────────┐
│              OpenClaw 消息处理流程                       │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 你发送消息                                          │
│     ↓                                                   │
│  2. Gateway 接收并路由到会话                            │
│     ↓                                                   │
│  3. 构建 Prompt（系统提示 + 工具 + 历史 + 消息）         │
│     ↓                                                   │
│  4. AI 模型决定调用哪个工具                              │
│     ↓                                                   │
│  5. 执行工具（读文件/搜索/发消息...）                   │
│     ↓                                                   │
│  6. 结果返回给 AI 模型                                   │
│     ↓                                                   │
│  7. AI 模型生成友好回复                                  │
│     ↓                                                   │
│  8. 发送回复给你                                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**关键点：**
- AI 模型是"大脑"，决定做什么
- 工具是"手脚"，执行具体操作
- Gateway 是"前台"，管理消息路由

### 2.4 架构组成（三要素）

```
┌─────────────────────────────────────────────────────────┐
│              OpenClaw 架构三要素                         │

│  🏛️ Gateway（网关）                                     │
│     • 消息入口和出口                                     │

│     • 任务调度                                           │
│     • 运行在你的服务器/电脑上                            │
│                                                         │
│  📱 Node（节点）                                        │
│     • 可选组件                                           │
│     • 用于连接手机/平板等设备                            │
│     • 可以访问设备特定功能（相机、位置等）               │
│                                                         │
│  🔌 Channel（渠道）                                     │
│     • 消息收发的渠道                                     │
│     • 支持：飞书、Telegram、WhatsApp、Discord 等         │
│     • 可以配置多个渠道，统一管理                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

     └───────────┼───────────┘
                 │

        ┌────────────────┐
        │    Gateway     │  ← 运行在你的服务器

        └────────┬───────┘
                 │
                 ▼
        ┌────────────────┐
        │     Node       │  ← 可选，连接手机等
        │    （节点）     │
        └────────────────┘
```

### 2.5 与其他 AI 工具的区别

**一句话总结：**

| 工具类型 | 代表 | 定位 | OpenClaw 差异 |
|----------|------|------|---------------|
| 对话型 | ChatGPT/Claude | 聊天助手 | OpenClaw 能真正做事 |
| 工具型 | Copilot/Cursor | 代码辅助 | OpenClaw 是通用助手 |
| Agent 型 | LangChain/Dify | 开发框架 | OpenClaw 更简单，面向个人 |
| 企业型 | 钉钉 AI/飞书助手 | 企业应用 | OpenClaw 数据本地、免费 |

**OpenClaw 的 5 大独特优势：**

```
1️⃣  真正能做事 —— 不只是聊天，能执行任务
2️⃣  数据在你手里 —— 自托管，隐私保护
3️⃣  完全免费 —— 开源软件，无订阅费
4️⃣  无限扩展 —— 可以写自己的 Skill
5️⃣  统一入口 —— 一个 Agent 管理所有渠道
```
