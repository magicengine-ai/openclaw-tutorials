## 4. 常见故障排查指南

### 4.1 安装问题

**问题 1：安装脚本报错"Permission denied"**

```bash
# 原因：没有执行权限
# 解决方案：
chmod +x install.sh
./install.sh

# 或使用 sudo
curl -fsSL https://openclaw.ai/install.sh | sudo bash
```

**问题 2：npm 安装速度慢/失败**

```bash
# 原因：网络问题或源慢
# 解决方案：使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install -g openclaw
```

**问题 3：command not found: openclaw**

```bash
# 原因：PATH 环境变量未包含 npm 全局路径
# 解决方案：
export PATH=$(npm config get prefix)/bin:$PATH

# 永久生效（添加到 ~/.bashrc 或 ~/.zshrc）
echo 'export PATH=$(npm config get prefix)/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

---

### 4.2 启动问题

**问题 4：Gateway 启动失败**

```bash
# 步骤 1：查看错误日志
openclaw logs --level error

# 步骤 2：常见原因排查
# - 端口被占用
lsof -i :3000
# 解决方案：修改 config.json 中的 port 或杀死占用进程

# - 配置文件错误
cat ~/.openclaw/config.json | python -m json.tool
# 解决方案：修复 JSON 格式

# - API Key 无效
# 解决方案：重新获取并更新配置

# 步骤 3：重启尝试
openclaw gateway restart
```

**问题 5：Gateway 启动后自动退出**

```bash
# 查看 systemd 日志
sudo journalctl -u openclaw -f

# 常见原因：
# 1. 配置文件路径错误
# 2. 工作区目录不存在
# 3. 权限问题

# 解决方案：
mkdir -p ~/openclaw/workspace
chmod 755 ~/.openclaw
```

### 4.3 消息渠道问题

**问题 6：飞书机器人不回复**

```
排查清单：
□ App ID 和 Secret 是否正确
□ 应用是否已发布
□ 权限是否已配置（发送消息、接收消息）
□ 事件订阅是否已启用
□ 订阅地址是否可访问
□ 机器人是否已添加到聊天

调试命令：
openclaw logs | grep feishu
```

**问题 7：Telegram 机器人无响应**

```bash
# 步骤 1：检查 Token
# 在 Telegram 搜索 @BotFather，发送 /mybots 查看

# 步骤 2：测试 API 连接
curl https://api.telegram.org/bot<TOKEN>/getMe

# 步骤 3：检查 Chat ID
# 发送消息给机器人，然后访问：
# https://api.telegram.org/bot<TOKEN>/getUpdates

# 步骤 4：查看日志
openclaw logs | grep telegram
```

**问题 8：Discord 机器人无法读取消息**

```
排查清单：
□ Message Content Intent 是否开启
□ Bot 权限是否包含 Read Messages
□ Bot 是否已添加到服务器
□ 频道权限是否允许机器人发言

调试：
# 在 Discord 开发者门户检查 Bot 设置
# 重新邀请 Bot 到服务器
```

### 4.4 模型连接问题

**问题 9：AI 模型调用失败**

```bash
# 步骤 1：检查 API Key
cat ~/.openclaw/config.json | grep apiKey

# 步骤 2：测试模型连接
openclaw ask "你好"

# 步骤 3：查看错误日志
openclaw logs --level error

# 常见错误：
# - 401 Unauthorized → API Key 错误
# - 429 Too Many Requests → 限流，稍后重试
# - 500 Server Error → 服务商问题，等待恢复
# - Timeout → 网络问题，检查连接
```

**问题 10：响应很慢（超过 10 秒）**

```
可能原因：
1. 网络延迟（特别是国外 API）
2. 模型负载高
3. 服务器性能不足
4. 上下文太长

解决方案：
- 使用国内模型（阿里云通义千问）
- 降低 contextLength 配置
- 升级服务器配置
- 检查网络连接
```

### 4.5 服务器问题

**问题 11：外网无法访问**

```bash
# 步骤 1：检查防火墙
sudo ufw status
sudo ufw allow 3000/tcp

# 步骤 2：检查云服务商安全组
# 登录控制台 → 安全组 → 添加入站规则

# 步骤 3：检查 Gateway 配置
# gateway.host 应该是 "0.0.0.0" 而非 "localhost"

# 步骤 4：测试本地访问
curl http://localhost:3000
```

**问题 12：服务开机未自启动**

```bash
# 检查 systemd 服务状态
sudo systemctl status openclaw

# 启用自启动
sudo systemctl enable openclaw

# 检查服务文件是否存在
ls -la /etc/systemd/system/openclaw.service

# 重新加载并启动
sudo systemctl daemon-reload
sudo systemctl start openclaw
```

---

### 4.6 性能问题

**问题 13：内存占用过高**

```bash
# 查看内存使用
htop
free -h

# 解决方案：
# 1. 限制 Node.js 内存
export NODE_OPTIONS="--max-old-space-size=512"

# 2. 降低 contextLength
# 编辑 config.json: "contextLength": 4096

# 3. 定期重启服务
sudo systemctl restart openclaw
```

**问题 14：磁盘空间不足**

```bash
# 查看磁盘使用
df -h

# 清理日志
sudo journalctl --vacuum-time=7d

# 清理旧日志文件
rm -rf ~/.openclaw/logs/*.log.*

# 配置日志轮转
# 在 config.json 中设置：
# "logging": { "maxFiles": 7, "maxSize": "10MB" }
```
