**第 1 题：Skills 系统的作用是什么？**

```
A. 让 Agent 记住信息
B. 扩展 Agent 的能力
C. 创建子 Agent
D. 设置定时任务

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：B**

**解析：** Skills 系统是能力扩展包，用于扩展 OpenClaw 的内置功能。A 是记忆系统，C 是子 Agent 系统，D 是 Cron 系统。

</details>


<details>
<summary>点击查看答案解析</summary>

**答案：C**

**解析：** 必需文件是 SKILL.md（描述文档）、package.json（项目配置）、index.ts（主入口）。README.md 是推荐但不必需。

</details>

**第 3 题：子 Agent 的两种运行模式是？**

```
A. fast 和 slow
B. run 和 session
C. sync 和 async
D. local 和 remote

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：B**

**解析：** 子 Agent 有两种运行模式：run（一次性，任务完成后结束）和 session（持久，长期运行等待指令）。

</details>

**第 4 题：记忆系统中，SESSION 结束后消失的是？**

```
A. 长期记忆
B. 短期记忆
C. 分类记忆
D. 文件记忆

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：B**

**解析：** 短期记忆是会话历史，会话结束后消失。长期记忆存储在文件中，持久化保存。

</details>

---

**第 5 题：Cron 表达式 "0 8 * * *" 表示？**

```
A. 每天 8 点
B. 每月 8 号
C. 每周 8 点
D. 每 8 分钟

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：A**

**解析：** Cron 表达式格式是"分 时 日 月 周"，"0 8 * * *"表示每天 8 点 0 分。

</details>

### 3.2 进阶题（选答）

**第 6 题：以下哪种场景最适合使用子 Agent？**

```
A. 简单查询天气
B. 复杂的市场研究报告
C. 设置一个提醒
D. 读取一个文件

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：B**

**解析：** 复杂的市场研究报告需要分工协作（研究、分析、写作、审查），适合多 Agent 协作。其他选项用单个 Agent 即可完成。

</details>

---

**第 7 题：记忆文件的最佳实践不包括？**

```
A. 分类存储
B. 定期 review
C. 存储所有对话详情
D. 安全存储凭证

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：C**

**解析：** 不应该存储所有对话详情，这会占用过多空间且难以检索。应该只存储重要信息，定期清理。

</details>

---

**第 8 题：Heartbeat 与 Cron 的主要区别是？**

```
A. Heartbeat 更精确
B. Cron 与主会话集成
C. Heartbeat 适合批量检查
D. Cron 更简单

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：C**

**解析：** Heartbeat 定期触发，适合批量检查任务。Cron 更精确，独立执行。Heartbeat 与主会话集成，Cron 配置稍复杂。

</details>

**第 10 题：故障排查演练**

```
场景：你的自动化任务突然不执行了。

请列出你的排查步骤（至少 5 步）：

1. _______________________________________________
2. _______________________________________________
3. _______________________________________________
4. _______________________________________________
5. _______________________________________________
```

<details>
<summary>点击查看答案解析</summary>

**参考答案：**

1. 检查任务状态：`openclaw cron list`
2. 查看任务是否启用：检查 enabled 字段
3. 查看执行历史：`openclaw cron runs --jobId xxx`
4. 检查 Gateway 状态：`openclaw gateway status`
5. 查看错误日志：`openclaw logs --level error`
6. 验证 Cron 表达式是否正确
7. 检查系统时间和时区设置
8. 重启 Gateway：`openclaw gateway restart`

</details>
