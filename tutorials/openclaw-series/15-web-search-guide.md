## 2. 基本搜索

### 2.1 第一次搜索

**对话示例：**

```
你：帮我搜索一下最新的 AI 新闻

OpenClaw: 好的，让我帮你搜索...

🔍 搜索结果：

1. **OpenAI 发布新模型 GPT-5**
   来源：TechCrunch
   时间：2 小时前
   摘要：OpenAI 今天发布了新一代模型...
   URL: https://techcrunch.com/...

2. **Google 更新 AI 系统**
   来源：The Verge
   时间：5 小时前
   摘要：Google 宣布对其 AI 系统进行重大更新...
   URL: https://theverge.com/...

3. **中国 AI 公司融资 10 亿美元**
   来源：36 氪
   时间：1 天前
   摘要：某 AI 初创公司完成新一轮融资...
   URL: https://36kr.com/...

共找到 127 条结果，显示前 5 条。
需要我详细展开某一条吗？
```

**对应的工具调用：**

```json
{
  "name": "web_search",
  "arguments": {
    "query": "AI 人工智能 最新新闻",
    "count": 5,
    "freshness": "week"
  }
}
```

### 2.2 搜索参数详解

```json
{
  "name": "web_search",
  "arguments": {
    "query": "搜索关键词",
    "count": 5,           // 结果数量 (1-10)
    "freshness": "week",  // 时间过滤
    "language": "zh",     // 语言
    "country": "CN"       // 地区
  }
}
```

| 参数 | 说明 | 可选值 | 默认值 |
|------|------|--------|--------|
| `query` | 搜索关键词 | 任意文本 | 必填 |
| `count` | 结果数量 | 1-10 | 5 |
| `freshness` | 时间过滤 | day/week/month/year | 无 |
| `language` | 语言 | en/zh/de/fr 等 | en |
| `country` | 地区 | US/CN/DE/FR 等 | US |

### 2.3 时间过滤

```
你：帮我找一下最近 24 小时的 AI 新闻

OpenClaw: 好的，搜索最近 1 天的结果...

[显示结果]

💡 提示：freshness 参数说明
- day → 最近 24 小时
- week → 最近 7 天
- month → 最近 30 天
- year → 最近 1 年
```

### 2.4 地区和语言过滤

## 3. 高级搜索技巧

### 3.1 精确搜索

```
❌ 模糊搜索：
"帮我查一下苹果"
（可能返回水果、公司、电影等）

✅ 精确搜索：
"帮我查一下苹果公司 2026 年新品发布"
（明确指定主题和时间）

✅ 更精确：
"搜索 Apple WWDC 2026 发布会，只要最近一周的新闻"
```

### 3.2 组合关键词

```
技巧：使用多个关键词缩小范围

示例：
"搜索 Python 数据分析 教程 2026"
"搜索 AI 医疗 应用 案例 中国"
"搜索 电动汽车 电池 技术 最新进展"
```

### 3.3 排除关键词

```
技巧：排除不相关的内容

示例：
"搜索 苹果 手机 -水果"
（排除水果相关的内容）

"搜索 Python 编程 -蛇 -动物"
（排除动物相关的内容）
```

### 3.4 指定网站搜索

```
技巧：在特定网站内搜索

示例：
"在 github.com 搜索 Python 项目"
"在 zhihu.com 搜索 AI 讨论"
"在 gov.cn 搜索政策文件"
```

## 4. 网页内容抓取

### 4.1 抓取网页正文

**对话示例：**

```
你：帮我抓取这个文章的内容：
https://example.com/ai-news-2026

OpenClaw: 好的，正在抓取网页内容...

📄 文章标题：2026 年 AI 发展趋势

📝 正文内容：

2026 年，人工智能领域将迎来多个重要突破...

（提取的正文内容，已去除广告和导航）

文章共 3500 字，阅读时间约 10 分钟。
需要我总结一下吗？
```

**对应的工具调用：**

```json
{
  "name": "web_fetch",
  "arguments": {
    "url": "https://example.com/ai-news-2026",
    "extractMode": "markdown",
    "maxChars": 10000
  }
}
```

### 4.2 提取模式

```
extractMode 参数：

markdown → 保留格式（标题、列表、链接等）
text     → 纯文本（无格式）

示例：
你：抓取这个网页，保留格式
OpenClaw: 使用 markdown 模式提取...

你：只要纯文本内容
OpenClaw: 使用 text 模式提取...
```

## 8. 搜索常见问题

### 8.1 搜索结果为空

```
❌ 问题：搜索不到结果

可能原因：
1. 关键词太具体
2. 时间范围太窄
3. 语言/地区限制太严

✅ 解决方案：
- 简化关键词
- 放宽时间范围
- 移除语言/地区限制

示例：
你：搜索"XXX 公司 2026 年 3 月 26 日 发布会"
（太具体，可能无结果）

改为：搜索"XXX 公司 2026 年 发布会"
```

### 8.2 搜索结果不相关

```
❌ 问题：搜索结果与需求不符

可能原因：
1. 关键词有歧义
2. 缺少限定词

✅ 解决方案：
- 添加限定词
- 排除不相关内容

示例：
你：搜索"苹果"
（可能返回水果、公司、电影）

改为：搜索"苹果公司 新品 发布"
```

### 8.3 网页抓取失败

```
❌ 问题：无法抓取网页内容

可能原因：
1. 网页需要登录
2. 有反爬虫机制
3. 网页结构复杂

✅ 解决方案：
- 尝试其他来源
- 使用浏览器截图
- 手动复制内容

示例：
你：抓取这个网页
OpenClaw: 抱歉，这个网页无法抓取。
        可能是需要登录或有反爬虫。
        我可以用浏览器截图给你看。
```
