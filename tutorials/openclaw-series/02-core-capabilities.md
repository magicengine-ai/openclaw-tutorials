## 2. 📁 文件操作能力

### 2.1 读取文件

**能做什么：**
- 读取文本文件（.txt, .md, .json, .py 等）
- 读取图片文件（.jpg, .png, .gif, .webp）
- 读取 PDF、Word、Excel（需要额外配置）
- 支持大文件分块读取

**示例：**
```bash
# 让 OpenClaw 读取文件
openclaw ask "帮我读一下今天的会议记录"
# 自动找到并读取 ~/workspace/meetings/2026-03-25.md
```

**内部实现：**
```
工具名：read
参数：path（文件路径）, offset（起始行）, limit（读取行数）
```

### 2.2 写入文件

**能做什么：**
- 创建新文件
- 覆盖已有文件
- 自动创建目录结构

**示例：**
```bash
openclaw ask "帮我创建一个待办清单，保存到 todo.md"
```

**内部实现：**
```
工具名：write
参数：path（文件路径）, content（文件内容）
```

### 2.3 编辑文件

**能做什么：**
- 精确替换文本
- 插入内容到指定位置
- 删除指定内容

**示例：**
```bash
openclaw ask "帮我把 README.md 里的版本号从 1.0 改成 1.1"
```

**内部实现：**
```
工具名：edit
参数：path, oldText（要替换的原文）, newText（新内容）
```

### 2.4 文件管理

**能做什么：**
- 列出目录内容
- 移动/复制文件
- 删除文件（可配置回收到垃圾桶）
- 搜索文件

**示例：**
```bash
openclaw ask "帮我整理一下下载文件夹，把图片都移到 pictures 目录"
```

## 3. 🔍 信息获取能力

### 3.1 网络搜索

**能做什么：**
- 使用 Brave Search API 搜索网页
- 支持时间过滤（最近 1 天/周/月）
- 支持语言/地区过滤
- 返回标题、URL、摘要

**示例：**
```bash
openclaw ask "帮我查一下最新的 AI 新闻"
openclaw ask "搜索 Python 教程，只要中文结果"
openclaw ask "找一下最近一周关于量子计算的新闻"
```

**内部实现：**
```
工具名：web_search
参数：
  - query（搜索词）
  - count（结果数量，1-10）
  - freshness（时间过滤：day/week/month/year）
  - language（语言：en/zh/de 等）
  - country（地区：US/CN/DE 等）
```

### 3.2 网页内容抓取

**能做什么：**
- 提取网页正文内容
- 去除广告和导航
- 转换为 Markdown 或纯文本
- 支持长内容截断

**示例：**
```bash
openclaw ask "帮我抓取这个文章的内容：https://example.com/article"
```

**内部实现：**
```
工具名：web_fetch
参数：
  - url（网页地址）
  - extractMode（markdown 或 text）
  - maxChars（最大字符数）
```

### 3.3 信息监控

**能做什么：**
- 定期检查网页/数据变化
- 价格监控
- 新闻监控
- 状态监控

**示例：**
```bash
# 通过定时任务实现
# 每 30 分钟检查一次商品价格
openclaw ask "帮我盯着这个商品，降价就通知我"
```

## 4. 🌐 浏览器自动化能力

### 4.1 浏览器控制

**能做什么：**
- 打开网页
- 点击元素
- 填写表单
- 截图
- 下载文件
- 执行 JavaScript

**示例：**
```bash
openclaw ask "帮我去 GitHub 上看一下我的项目有多少 star"
openclaw ask "帮我登录 Gmail 检查一下新邮件"
```

**内部实现：**
```
工具名：browser
动作：
  - open（打开网页）
  - click（点击元素）
  - type（输入文字）
  - screenshot（截图）
  - snapshot（获取页面快照）
  - evaluate（执行 JS）
```

### 4.2 页面快照

**能做什么：**
- 获取页面结构化信息
- 识别按钮、链接、表单
- 支持 AI 模式和 ARIA 模式

**示例：**
```bash
# 获取页面可操作元素列表
browser snapshot --refs aria
```

### 4.3 自动化场景

**典型用例：**

| 场景 | 操作 |
|------|------|
| **自动填表** | 打开表单 → 填写字段 → 提交 |
| **数据抓取** | 打开列表页 → 提取数据 → 保存 |
| **截图监控** | 定期截图 → 对比变化 → 通知 |
| **自动化测试** | 打开页面 → 点击 → 验证结果 |

## 5. 💬 消息通信能力

### 5.1 支持的平台

| 平台 | 状态 | 功能 |
|------|------|------|
| **Telegram** | ✅ | 收发消息、文件、图片 |
| **WhatsApp** | ✅ | 收发消息、文件 |
| **Discord** | ✅ | 收发消息、嵌入卡片 |
| **飞书 (Lark)** | ✅ | 收发消息、文档、日历 |
| **微信** | ⚠️ | 需要额外配置 |
| **Slack** | ✅ | 收发消息、文件 |
| **Email** | ✅ | 收发邮件（需配置 SMTP） |

### 5.2 消息功能

**能做什么：**
- 发送文本消息
- 发送图片/文件
- 发送投票
- 发送表情回复
- 创建话题/线程
- 编辑/删除消息

**示例：**
```bash
# 发送消息到群聊
openclaw message send --channel feishu --message "会议改到下午 3 点"

# 发送文件
openclaw message send --channel telegram --file report.pdf

# 创建投票
openclaw message send --channel discord --poll "中午吃什么？" --options "火锅,烧烤,沙拉"
```

### 5.3 消息管理

**能做什么：**
- 搜索历史消息
- 按条件过滤（发送者、时间、类型）
- 获取群成员列表
- 管理话题回复

## 7. 🔧 系统控制能力

### 7.1 命令执行

**能做什么：**
- 执行 Shell 命令
- 后台运行长任务
- 管理进程
- PTY 模式（交互式命令）

**示例：**
```bash
# 执行简单命令
openclaw ask "帮我运行 git status"

# 后台运行
openclaw ask "帮我下载这个大文件，完成后通知我"

# 交互式命令
openclaw ask "帮我启动一个 Python 交互式会话"
```

**内部实现：**
```
工具名：exec
参数：
  - command（命令）
  - timeout（超时时间）
  - background（后台运行）
  - pty（伪终端模式）
```

### 7.2 进程管理

**能做什么：**
- 列出运行中的进程
- 查看进程日志
- 向进程发送输入
- 终止进程

**示例：**
```bash
# 查看后台任务
process list

# 查看日志
process log --sessionId xxx

# 终止任务
process kill --sessionId xxx
```

## 9. 🤖 Agent 系统

### 9.1 子 Agent

**能做什么：**
-  spawn 独立子 Agent 处理专门任务
-  子 Agent 可以有自己的模型配置
-  支持流式输出到父 Agent
-  支持 ACP 协议（与 Codex 等集成）

**示例：**
```bash
# 启动子 Agent 处理研究任务
sessions_spawn --task "帮我研究一下最新的 LLM 技术" --runtime subagent

# 查看子 Agent 状态
subagents list

# 给子 Agent 发送指令
subagents steer --target xxx --message "继续深入调查"
```

## 10. 能力边界与限制

### ✅ 擅长的事

- 结构化任务（有明确步骤）
- 信息收集与整理
- 文件处理与转换
- 定时重复性工作
- 跨平台消息同步

### ⚠️ 有限制的事

| 限制 | 说明 |
|------|------|
| **实时性** | 依赖轮询，不是真正的实时推送 |
| **复杂 UI** | 浏览器自动化对动态页面支持有限 |
| **大文件** | 文件读取有大小限制（50KB/2000 行） |
| **并发** | 同时处理多个任务需要合理配置 |
| **模型依赖** | 能力受底层 AI 模型能力限制 |

### ❌ 做不到的事

- 破解加密/绕过安全限制
- 访问付费墙后的内容（没有账号）
- 100% 准确的决策（AI 会犯错）
- 预测未来/访问非公开信息
