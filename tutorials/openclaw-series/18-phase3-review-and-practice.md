```
┌─────────────────────────────────────────────────────────┐
│              有效沟通的 4 个原则                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1️⃣  清晰具体                                            │
│     "帮我读取 ~/workspace/test.md"                      │
│     而非"帮我弄一下那个文件"                            │
│                                                         │
│  2️⃣  完整上下文                                          │
│     "总结一下刚才我让你读取的那个会议记录"              │
│     提供足够背景信息                                    │
│                                                         │
│  3️⃣  分步复杂任务                                        │
│     复杂任务分解为多个简单步骤                          │
│     一步一步执行                                        │
│                                                         │
│  4️⃣  指定输出格式                                        │
│     "用表格形式展示"                                    │
│     "输出为 Markdown 列表"                               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**提示词技巧速查：**

| 技巧 | 示例 | 效果 |
|------|------|------|
| 角色设定 | "你是一个专业的文件管理员..." | Agent 按角色定位回复 |
| 任务分解 | "请按照以下步骤操作：1...2...3..." | 按步骤执行，更可靠 |
| 示例引导 | "像这样：输入 A→输出 B" | Agent 模仿示例格式 |
| 约束条件 | "只要最近 3 天的，最多 5 条" | 在约束范围内工作 |
| 确认机制 | "删除前请先列出来让我确认" | 避免误操作 |

### 3.1 基础题（必答）

**第 1 题：以下哪项不是有效沟通的原则？**

```
A. 清晰具体
B. 模糊暗示
C. 分步复杂任务
D. 指定输出格式

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：B**

**解析：** 有效沟通的 4 个原则是：清晰具体、完整上下文、分步复杂任务、指定输出格式。"模糊暗示"会导致 Agent 无法准确理解需求。

</details>

---

**第 2 题：编辑文件时，edit 工具需要什么条件？**

```
A. 文件路径
B. 原文本和新文本
C. 原文本必须精确匹配
D. 以上都是

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：D**

**解析：** edit 工具需要文件路径、原文本（必须精确匹配）、新文本。原文本不匹配会导致编辑失败。

</details>

---

**第 3 题：web_search 的时间过滤参数不包括？**

```
A. day
B. week
C. hour
D. month

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：C**

**解析：** web_search 的 freshness 参数可选值为：day（24 小时）、week（7 天）、month（30 天）、year（1 年）。不支持 hour。

</details>

---

**第 4 题：浏览器操作中，获取页面可操作元素用什么？**

```
A. screenshot
B. snapshot
C. evaluate
D. navigate
```

<details>
<summary>点击查看答案解析</summary>

**解析：** snapshot 用于获取页面快照，显示可操作元素列表。screenshot 是截图，evaluate 是执行 JS，navigate 是导航。

</details>

**第 7 题：任务优先级矩阵中，应该优先处理哪类任务？**

```
A. 重要且紧急
B. 重要不紧急
C. 紧急不重要
D. 不紧急不重要

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：A**

**解析：** 优先级矩阵中，重要且紧急的任务应该立即处理。重要不紧急的任务计划做，紧急不重要的任务可以授权，不紧急不重要的任务少做。

</details>

**第 8 题：以下哪个不是文件操作的安全最佳实践？**

```
A. 限制访问范围
B. 重要操作前确认
C. 直接覆盖重要文件
D. 定期备份

答案：____
```

<details>
<summary>点击查看答案解析</summary>

**答案：C**

**解析：** 直接覆盖重要文件是危险操作。安全做法是：限制访问范围、重要操作前确认、修改前备份、开启操作日志。

</details>

**第 10 题：故障排查演练**

```
场景：你的 OpenClaw 突然无法执行文件操作了。

请列出你的排查步骤（至少 5 步）：

1. _______________________________________________
2. _______________________________________________
3. _______________________________________________
4. _______________________________________________
5. _______________________________________________
```

<details>
<summary>点击查看答案解析</summary>

**参考答案：**

1. 查看错误日志：`openclaw logs --level error`
2. 检查配置文件：`cat ~/.openclaw/config.json`
3. 确认 workspace 配置是否正确
4. 检查文件权限：`ls -la ~/openclaw/workspace`
5. 测试简单文件操作：`openclaw ask "读取 ~/workspace/test.md"`
6. 检查 tools 配置是否禁用了文件操作
7. 重启 Gateway：`openclaw gateway restart`

</details>
