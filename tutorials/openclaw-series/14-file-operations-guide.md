## 2. 读取文件

### 2.1 基本读取

**对话示例：**

```
你：帮我读取 ~/workspace/meetings/2026-03-26.md 文件

OpenClaw: 好的，让我读取这个文件...

[文件内容]
# 2026-03-26 团队会议

## 参会人员
- 张三
- 李四
- 王五

## 讨论事项
1. 项目进度汇报
2. 下周工作计划
3. 技术选型讨论

## 决定事项
- 下周五前完成第一阶段开发
- 使用 React 作为前端框架

[读取完成]

文件共 15 行，需要我帮你总结吗？
```

**对应的工具调用：**

```json
{
  "name": "read",
  "arguments": {
    "path": "~/workspace/meetings/2026-03-26.md"
  }
}
```

### 2.2 读取大文件

对于大文件，可以指定读取范围：

```
你：帮我读取 ~/workspace/large-log.log 文件的前 100 行

OpenClaw: 好的，读取前 100 行...

[显示前 100 行内容]

这是文件的前 100 行，共 2.5KB。需要继续读取更多内容吗？
```

**参数说明：**

```json
{
  "name": "read",
  "arguments": {
    "path": "~/workspace/large-log.log",
    "offset": 1,
    "limit": 100
  }
}
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `path` | 文件路径 | 必填 |
| `offset` | 起始行号（1 开始） | 1 |
| `limit` | 最大读取行数 | 2000 |

### 2.3 读取多个文件

```
你：帮我读取 workspace 里所有的 README 文件

OpenClaw: 好的，让我先找到所有 README 文件...

找到了 3 个 README 文件：
1. ~/workspace/project-a/README.md
2. ~/workspace/project-b/README.md
3. ~/workspace/project-c/README.md

正在逐个读取...

[显示每个文件的内容]

需要我对比这些文件的内容吗？
```

### 2.4 读取文件时的常见错误

```
❌ 错误 1：文件不存在
你：读取 ~/workspace/not-exist.md
OpenClaw: 抱歉，这个文件不存在。
        请检查路径是否正确。

✅ 解决：先确认文件存在
你：列出 ~/workspace 目录下的文件

❌ 错误 2：路径超出允许范围
你：读取 /etc/passwd
OpenClaw: 抱歉，这个路径不在允许访问的范围内。
        我只能访问 workspace 目录内的文件。

✅ 解决：使用允许范围内的路径
你：读取 ~/workspace/config.json
```

## 3. 写入文件

### 3.1 创建新文件

**对话示例：**

```
你：帮我创建一个新文件，路径是 ~/workspace/notes/todo.md，
内容是今天的待办事项

OpenClaw: 好的，正在创建文件...

✅ 文件已创建：~/workspace/notes/todo.md

内容如下：
# 2026-03-26 待办事项

1. [ ] 完成项目报告
2. [ ] 回复客户邮件
3. [ ] 准备下周会议

需要我修改内容吗？
```

**对应的工具调用：**

```json
{
  "name": "write",
  "arguments": {
    "path": "~/workspace/notes/todo.md",
    "content": "# 2026-03-26 待办事项\n\n1. [ ] 完成项目报告\n..."
  }
}
```

### 3.2 覆盖现有文件

```
⚠️ 注意：write 会覆盖现有文件！

你：帮我更新 ~/workspace/config.json 文件

OpenClaw: 好的，新的内容是...

⚠️ 警告：这个操作会覆盖现有文件内容。
        确定要继续吗？

你：确定

OpenClaw: ✅ 文件已更新
```

**安全建议：**

```
✅ 推荐做法：
1. 重要文件编辑前先备份
2. 使用 edit 而不是 write 进行小修改
3. 覆盖前让 Agent 显示新内容确认

你：修改前先备份原文件
OpenClaw: 好的，已创建备份：~/workspace/config.json.bak
```

### 3.3 自动创建目录

```
你：帮我创建文件 ~/workspace/projects/new-project/README.md

OpenClaw: 好的，目录不存在，我先创建目录结构...

✅ 已创建目录：~/workspace/projects/new-project/
✅ 已创建文件：README.md

内容如下：
# New Project

项目描述...
```

## 4. 编辑文件

### 4.1 精确替换文本

**edit 工具用于精确修改文件内容：**

```
你：帮我把 ~/workspace/config.json 里的版本号从 1.0 改成 1.1

OpenClaw: 好的，我先读取文件查看当前内容...

找到以下内容：
"version": "1.0"

确认要替换为：
"version": "1.1"

吗？

你：确认

OpenClaw: ✅ 已替换，文件已更新
```

**对应的工具调用：**

```json
{
  "name": "edit",
  "arguments": {
    "path": "~/workspace/config.json",
    "oldText": "\"version\": \"1.0\"",
    "newText": "\"version\": \"1.1\""
  }
}
```

### 4.2 编辑多行内容

```
你：帮我把 ~/workspace/report.md 里的"负责人：张三"
改成"负责人：李四"

OpenClaw: 好的，正在查找并替换...

✅ 已找到 1 处匹配，已替换

需要我查看修改后的内容吗？
```

### 4.3 批量编辑

```
你：帮我把 ~/workspace/src 目录下所有 Python 文件里的
print 语句都改成 logging.info

OpenClaw: 这个操作会影响多个文件，让我先确认一下...

找到 5 个 Python 文件包含 print 语句：
1. main.py - 3 处
2. utils.py - 2 处
3. config.py - 1 处
4. ...

确定要全部替换吗？

你：确定

OpenClaw: ✅ 已完成，共替换 8 处
```

### 4.4 编辑失败的情况

```
❌ 错误：原文本不匹配

你：把"version: 1.0"改成"version: 1.1"
OpenClaw: 抱歉，没有找到完全匹配的文本。
        文件中的实际内容是："version": "1.0"
        （注意引号和冒号后的空格）

✅ 解决：精确匹配原文本
你：把"version": "1.0"改成"version": "1.1"
```

## 7. 文件操作安全

### 7.1 权限配置

```json
// config.json 中的 workspace 配置
"workspace": {
  "path": "~/openclaw/workspace",
  "allowWrite": true,      // 允许写入
  "maxFileSize": 10485760, // 最大 10MB
  "allowedPaths": [        // 允许访问的路径
    "~/openclaw/workspace"
  ]
}
```

### 7.2 安全最佳实践

```
✅ 推荐做法：

1. 限制访问范围
   - 只允许访问 workspace 目录
   - 不要开放家目录或系统目录

2. 重要操作前确认
   - 删除文件前要求确认
   - 覆盖文件前显示新内容

3. 定期备份
   - 重要文件修改前自动备份
   - 定期备份整个 workspace

4. 日志记录
   - 开启文件操作日志
   - 定期审计操作记录
```

### 7.3 危险操作警示

```
⚠️ 以下操作需要特别小心：

❌ 删除文件
你：删除 ~/workspace/important.md
OpenClaw: ⚠️ 警告：这个操作不可逆！
        确定要删除吗？（输入 yes 确认）

❌ 覆盖重要文件
你：覆盖 ~/workspace/config.json
OpenClaw: ⚠️ 警告：这会覆盖现有文件！
        建议先备份，确定要继续吗？

❌ 访问敏感路径
你：读取 /etc/passwd
OpenClaw: ❌ 拒绝：这个路径不在允许范围内
```
